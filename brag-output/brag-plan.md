# Brag Plan: Prospect and Outreach Agent

## What is this app?
One manager agent takes a target buyer profile, sends a research agent to pull people from the CRM, the contact database and web search, scores and ranks each lead, then sends an outreach agent to write a fact-checked email for each one.

## The angle
A quiet Tokyo-night product film. One sales rep, one clock, too many tabs. Then the same work drawn as a calm, minimal agent map: manager on top, two helpers below, each with its own small set of tools. Restraint is the brand: thin type, hairlines, kanji scene numbers, teal shadows and magenta highlights.

## Hook (first 2-3 seconds)
A large, thin "9:02 am" fades up on near-black with a soft neon bokeh behind it. The narrator says "You know this one." The clock then shrinks into the corner, and the tab mess starts.

## Key moments (the middle)
- Windows stack up: CRM, contact list, ten search tabs. The clock races from 9:02 to 10:04. All of it collapses into one lonely email card.
- The agent map draws itself: a target chip drops into the Manager Agent, two hairline branches split to Research Agent and Outreach Agent.
- Research tools light up one at a time (CRM records, contact database, email check, web search for news and job posts), then four leads arrive.
- Each lead gets a score, the list re-sorts, the best fit rises to the top, the out-of-profile lead is set aside.
- The outreach agent types a short email. The fact in it is underlined and tied to its source. A "Synced to CRM" chip lands.

## Outro / punchline
"Prospect and Outreach Agent." A single "Run prospecting" button (the real button label from the dashboard) gets one click.

## User flow worth showing
Set a target (role, industry, size, region) → run → ranked shortlist with score breakdown → email draft tied to real signals. This flow drives scenes 2-5.

## Tone
- Preset: cinematic (pacing) mixed with polished (restraint)
- Creative direction: aesthetic minimalism, Tokyo night LUT (teal shadows, magenta highlights, soft sodium amber, film grain, bokeh)
- Interpretation: slow fades, generous negative space, hairline geometry, no bold slams. Only accents move fast.

## Format: landscape — 1920x1080
## Duration: 36.9s
Over the usual 15-25s /brag window on purpose: the brief asks for five content beats (problem, manager, research tools, scoring, outreach + CRM) with natural narration. The narration was cut twice to reach this length.

## Visual identity
- Base from the project: dark canvas #090A0C, text #EDEDED, Plus Jakarta Sans + JetBrains Mono (from frontend/src/index.css)
- Tokyo grade on top: ink #070B10, teal #3FD0C9, magenta #FF5C8A, sodium amber #F2B25C, muted #8C9CA5
- Noto Sans JP (subset) for kanji scene numbers: 一 二 三 四 五 六, plus 管理 (manager), 調査 (research), 連絡 (outreach), 優先 (priority), 見込み客 (prospect)
- Strongest visual: the agent map from assets/arch.png, redrawn minimal with no vendor names

## Rules from the user
- No stack or vendor names anywhere (no agent platform, no seller brand, no vector DB, no search/data vendor names). The data sources are named by role: CRM, contact database, web search.
- Script: no "not X, but Y" style contrasts; simple words (ASD-STE100 spirit); varied, slightly loose rhythm.
- Male voice, natural: Kokoro `am_michael`, speed 1.06.

## Fictional data
All people and companies on screen are made up (Maya Chen / Northwind Cloud, Arjun Rao / Ledgerly, Elena Ruiz / Brightpath, Tom Becker / Corvel Group). No real prospect data from the project is used.

## Voiceover script
1. (0.5s) You know this one. You open the CRM, then a contact list, then ten search tabs... and an hour later, you have one email.
2. (8.55s) So we made a manager agent. Tell it who to reach, and it hands the work to two helpers.
3. (14.36s) The research agent pulls people from your CRM, checks each email, and searches the web for fresh news and job posts.
4. (22.4s) Every lead gets a score. Best fit goes first.
5. (25.7s) Then the outreach agent writes each email from real facts. And your CRM stays up to date.
6. (31.99s) Prospect and Outreach Agent. Pick a target, and press run.

## Audio direction
- Role: cinematic support under narration
- Music: happy-beats-business-moves-vol-1 (only bundled track present), 120 BPM, held low (0.14) under the voice, fade in 1s, fade out 2.5s
- Music cue guidance: preset read. Beat grid lands on x.02 / x.52. Locks: manager node 8.52, rows 19.52/20.02/20.51/21.01, scores 22.51, re-sort 24.02, outro title 32.02
- Audio-reactive: subtle; music RMS makes the neon bokeh breathe
- SFX posture: sparse; soft drops for cards, small clicks for tool chips, a few key ticks for typing, one bell for the manager and one for the title, a mouse click on Run
- Restraint rule: nothing loud over the voice; no whooshes, no stacked hits

## Storyboard
1. The problem — 0-8.3s — clock hook, CRM / contact list / search tabs stack, clock races, collapse to "1 email"
2. The manager — 8.3-14.15s — Manager Agent node, target chip, two branches to Research and Outreach
3. Research — 14.15-22.2s — four tool chips one by one, four leads arrive on the beat grid
4. Prioritize — 22.2-25.5s — scores count up, list re-sorts, one lead set aside
5. Outreach — 25.5-31.8s — tools (playbook, fact check, CRM sync), email types out, fact underlined to its source, synced chip
6. Outro — 31.8-36.93s — product name, Run prospecting button click
